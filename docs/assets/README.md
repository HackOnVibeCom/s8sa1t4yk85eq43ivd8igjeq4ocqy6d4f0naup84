# Screenshots and media

The repository includes sample venue/avatar images under `public/images`. They are application assets, not screenshots proving that a production site or user journey has been tested.

No verified production screenshots are included in this package. Before submission or a public release, capture current screenshots from the actual deployment and ensure that they contain no personal data, credentials, private dashboard information or misleading sample-to-live claims.

## Recommended captures

- Landing page at desktop and mobile widths
- Venue results and active accessibility filters
- A venue detail page with its evidence/status context visible
- Contribution form before final submission
- Assistant text interaction, only after confirming the deployed endpoint works
- Mobile navigation and assistant presentation

Label sample data as sample data. Do not present a screenshot as proof of deployment or persisted functionality.
