# HackOnVibe 2026 — Submission readiness checklist

The current statuses below are the statuses supplied by the team. Documentation preparation does not complete an organizer submission.

## Requirement status

| Requirement | Current supplied status | Completion condition |
|---|---|---|
| Repository invitation | Complete | No action |
| All members accepted invitations | Complete | No action |
| Team code contributions | Complete | No action |
| Merged pull request | Complete | No action |
| Project website submitted | Pending | Enter a verified public website URL in the dashboard |
| Customer journey submitted | Pending | Upload the finished five-minute video and provide its public URL |
| Questionnaire submitted | Pending | Obtain, complete and submit the official organizer questionnaire |

## Actionable final checklist

- [ ] Confirm the public deployment works; inspect the current deployment and use its actual URL.
- [ ] Test the website as an external judge, including the signed-out path and mobile layout.
- [ ] Confirm the primary user journey using the configured Supabase project and actual test account.
- [ ] Confirm the Gemini assistant returns a real successful response; use text unless voice is separately confirmed.
- [ ] Check demo account credentials and share them only through an organizer-approved private channel. No built-in demo account exists.
- [ ] Record and review the complete five-minute customer journey video.
- [ ] Upload the video to the organizer-approved/public host; verify public access and copy the real share URL.
- [ ] Obtain the official questionnaire from the organizer's Discord or submission dashboard.
- [ ] Map the prepared answer bank to the official questions and edit for their exact wording/limits.
- [ ] Submit the verified website URL, customer journey video URL and completed official questionnaire.
- [ ] Reopen the submission dashboard and confirm that all three statuses changed from pending.

## Important

A project description is not a website submission. A storyboard is not a recorded video. An answer bank is not the official questionnaire. Do not mark any of these three items complete until the actual submission is completed and verified in the HackOnVibe dashboard.
